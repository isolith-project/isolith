## How to read this

- The register is the commitment surface. A capability that is
  absent is a decision, not an accident (`not-scoped` exists to
  keep it visible).
- Status moves only `not-scoped -> planned -> building ->
  shippable`, and only while a green accepted test proves the
  new claim (the register's upgrade rule, decision #19).
- Vendor cells are reference only: how CATIA and SolidWorks
  ship the capability today. They are not commitments.
