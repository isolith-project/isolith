## What this is

The geometry-accuracy harness for the P5 native lane, per the ratified
P5-M1-T03 alpha ADR (§5 P5-M3-T02, §8 guardrail): it diffs geometry OUR tooling
extracts from a native sample against the output an EXTERNAL converter produces
from the SAME file, and reports a tolerance DISTRIBUTION. The external-converter
output is used STRICTLY as test-only ground truth for our own testing: never a
source of format internals, never shipped, never claimed as the product
(P5-M1-T03 §6 clean-room line — the same rule the P1-M3 commercial-reader audit
applied to capability claims).

Deliberately honest-by-construction (program anti-fabrication doctrine):

- a pair is **measured** only when real, readable geometry was read on BOTH
  sides and the metrics were computed (symmetric vertex-sampled Hausdorff +
  signed divergence volume compare + tolerance distribution);
- anything that can't be read is a **classified skip** from a closed taxonomy
  with a machine reason — the harness NEVER invents a fidelity number.

## Metrics (honest method disclosure)

- `symmetric_hausdorff`: two-sided vertex-sampled Hausdorff. For every vertex of
  mesh A the exact minimum distance to the triangle mesh B is computed, and vice
  versa; the report states `method: "vertex"` and the na/nb counts. This is a
  lower bound on the true surface Hausdorff — never claimed as exact.
- `tolerance_distribution` (the P5-M3-T02 acceptance metric): per-vertex
  distance percentiles (p50/p90/p99/p100) over BOTH sides' sampled distances,
  PLUS a cumulative ladder of tolerance bins scaled to the A-side bounding-box
  diagonal (`fraction_within` — fraction of A vertices inside each bin). This is
  a distribution, not a single epsilon: it pins the measured epsilon against the
  converter reference per the ADR guardrail.
- `volume`: signed divergence-theorem volume (exact for closed, consistently
  wound shells) on BOTH sides plus `volume_delta` and `volume_rel_error`, so a
  mixed-winding fixture is visible as an honest observation (the box fixture
  itself is mixed-winding: signed vol -1/3 on BOTH sides, delta 0.0) rather
  than hidden.
- Also reported: vertex/triangle counts per side (tessellation density) and the
  reference `provenance` block (which converter/version produced the ground
  truth).

## Clean-room / scope boundary

- The REFERENCE is produced by an independent external converter (FreeCAD OCC
  kernel) reading the same native file, through the documented committed
  generator `corpus/tools/gen_freecad_reference.py`. It is test-only ground
  truth; the harness never reads format internals from it and never ships it.
- The NATIVE side (`read_native`) understands the formats our own clean-room
  tooling reads TODAY (STL ASCII + binary, stdlib-only). When P5-M3-T01's native
  CATPart B-Rep reader lands, it registers behind the same `read_native` seam
  (library call or external CLI) without changing the runner/report surface —
  mirroring the regression.py `OEP_CGR_READER` pattern and step_fidelity's
  read seam.
- CI-safe: the acceptance test + committed fixtures need no live NAS and no
  FreeCAD at test time (the reference is a committed file); the generator is
  documented and reproducible for operators who have the converter.

## Skip taxonomy (closed set)

pair-missing-on-disk | native-unreadable | reference-unreadable |
reference-unavailable | no-native-geometry | no-reference-geometry | not-a-mesh |
io-error

There is NO `fail` bucket: an introspection error becomes a classified row;
a crash in one pair never aborts the sweep (per-pair try/except).
