# 3DXML ASCII writer for the internal tessellation mesh (P3-M4-T01)

Status: delivered 2026-10-15 on branch `task/p3m4-3dxml-writer-1015a`
(Kanban t_df7b159f). Scope: writer from the internal indexed-triangle mesh
(`positions: &[[f32; 3]]` + `triangles: &[[u32; 3]]`) to the tessellated-ASCII
branch of 3DXML — both the standalone ASCII `.3DRep` markup and a complete
deterministic ZIP-archive `.3dxml` package. License-compliant, internal-use
build (see License posture below).

## What the writer does

`oep_3dxml::ascii` (crate `oep-3dxml`, dependency-free):

- `write_rep_markup(positions, triangles, opts, w)` — the core conversion:
  emits the ASCII `XMLRepresentation` rep (hex notebook P1-M2-T04 §4.2):
  XML declaration; `XMLRepresentation version="1.0"`
  `xmlns="http://www.3ds.com/xsd/3DXML"`; `Root xsi:type="BagRepType"` ->
  `Rep xsi:type="BagRepType"` -> `Rep xsi:type="PolygonalRepType"`;
  `<Faces><Face strips="a b c,d e f,..."/>`; `<VertexBuffer><Positions>
  x y z,x y z,...</Positions>`. Positions are comma-separated "x y z"
  triples; face strips are comma-separated runs of space-separated vertex
  indices, ONE 3-index run per triangle (a triangle strip of 3 indices
  decodes to exactly one triangle, so the mesh round-trips losslessly). No
  normals are emitted — the source triangle mesh carries none and the writer
  never invents data.
- `write_package(positions, triangles, opts, w)` — wraps the rep into a valid
  ZIP-archive 3DXML: `Manifest.xml` (its `<Root>` names the model doc),
  `<name>.3dxml` (Header/SchemaVersion 4.0 + Title/Author/Generator/Created,
  ProductStructure root="1" with Reference3D + Instance3D identity
  RelativeMatrix, `ReferenceRep format="TESSELLATED" version="1.0"`
  `associatedFile="urn:3DXML:<name>.3DRep"`), and `<name>.3DRep` (the ASCII
  rep). Three STORED members, fixed DOS timestamp, UTF-8 names, PKWARE
  CRC-32 — from the public PKWARE APPNOTE (minimal hand-rolled ZIP writer,
  keeping the crate dependency-free). Byte-identical for a given input.
- `WriterOpts { product_name, author, timestamp }` — `timestamp` empty omits
  `<Created>` (golden tests are byte-deterministic; the example passes a real
  date to exercise the element).
- Errors typed, never panic; validation runs BEFORE any byte is written so a
  failed call emits nothing: `EmptyMesh`, `IndexOutOfRange`, `NonFiniteVertex`,
  `DegenerateTriangle` (zero-area, same rule as P2-M2-T02 STL), `Io`.

Input is consumed as plain slices so the module is independent of the
concrete `Mesh` type (docs/layout.md: no cross-crate path deps until the P6
importer hub) yet trivially callable with `mesh.vertices()`/`mesh.triangles()`.

## License posture (internal-use spec)

- The 3DXML XSD/user's guide is Dassault's, available under a free
  internal-use license (process recorded in P1-M1-T02). NOTHING from that
  licensed spec is reproduced here or in any committed file — no XSD text,
  no user's-guide quotes. The writer's markup reflects only (a) observed
  bytes of the public MIT/Apache-2.0 samples (hex notebook §4), and (b)
  our own structural decisions documented with `[uncertain]` markers.
- The ZIP framing is public PKWARE APPNOTE knowledge.
- This writer produces our own mesh data in a conformant interchange shell,
  for internal use; redistribution posture of 3DXML output is a separate
  legal lane (P1-M1-T02/P1-M2-T04 record the clean-room invariant).

## Notes / fidelity budget (feeds P3-M4-T02 round trip and P3-M1 reader)

- Writer `version="1.0"` is a choice (matches the Abaqus-author rep family);
  `1.2` (CATIA V5 family) is equally a string attribute `[uncertain]` —
  readers must accept any version string.
- One `<Face>` per mesh with multiple comma-separated 3-index runs is a valid
  strips encoding; the notebook observed multi-index runs (real strips), so a
  reader that implements N-index -> N-2 triangles handles both. Losslessness
  is exact on our side.
- Minimal product structure (single Reference3D/Instance3D identity transform,
  no materials/Osm) targets the tessellated-ASCII branch only. Material and
  Gregory-patch expectations are out of this card's scope.
- Numbers are shortest round-trip f32 (Rust Display / Python `%g` agree on
  the exact 0/1 box corners the golden is locked to).
- `<Created>` embeds a caller-supplied string; empty omits it. Member
  filenames use `product_name` verbatim (documented limitation: internal-use,
  file-name-safe names).
