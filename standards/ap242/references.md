# AP242 — Official Reference Sources

All links verified against the live network at the time of writing. Full standards
are NOT vendored here (copyright); these pointers lead to official sources and
publicly available implementation guidance.

## Official / standards bodies

- ISO 10303-242 product page (editions, status, abstract):
  https://www.iso.org/standard/84667.html
- ISO 10303-242:2025 (Edition 4) / edition status — search ISO catalogue for
  "10303-242" via the ISO price/catalogue page (URL above), or consult ISO/TC 184/SC 4:
  https://www.iso.org/committee/54158.html

## AP242 project / implementer portals

- STEP AP242 project portal (overview, use cases, benchmarks, one-page summary):
  https://www.ap242.org
- AP242 Edition 2/3 announcement pages (project history):
  https://www.ap242.org/edition-2.html
- CAx Implementor Forum (CAx-IF) — recommended practices, test rounds:
  https://www.cax-if.org
- CAx-IF PMI Recommended Practices (public PDF):
  https://www.mbx-if.org/home/wp-content/uploads/2024/05/rec_pracs_pmi_v40.pdf

## Benchmarks / conformance material

- STEP AP242 Benchmarks (CAD + PDM test cases, public reports):
  http://benchmark.ap242.org
- NIST STEP-related resources (introduction, MBE work) — official page:
  https://www.nist.gov/ctl/smart-connected-systems-division/smart-connected-manufacturing-systems-group/step-nist
- NIST STEP File Analyzer (useful reference tooling):
  https://tsapps.nist.gov/publication/get_pdf.cfm?pub_id=920696

## Recommended practice documents

- CAx-IF Recommended Practices — PMI (see URL above).
- CAx-IF Recommended Practices index and annual test rounds:
  https://www.cax-if.org (member area hosts current EXPRESS schema for testing).

## Note on redistribution

The ISO 10303-242 PDF is ISO-copyrighted and must not be committed to this repo.
Use the ISO product page for acquisition. Public informational material (ap242.org
overview, benchmark reports, CAx-IF recommended practices) may be linked and quoted
fairly with attribution.
