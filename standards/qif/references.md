# QIF — Official Reference Sources

All links verified against the live network at the time of writing. QIF is freely
available to implementers; the full standard and XSDs live at the official DMSC
download, not in this repo.

## Official / standards bodies

- DMSC (Digital Metrology Standards Consortium) — main portal:
  https://qifstandards.org
- QIF 3.0 free download (registration form):
  https://qifstandards.org/download
- QIF "About QIF" (what it is):
  https://qifstandards.org/about-qif
- ISO 23952:2020 product page (ISO-copyrighted PDF sold here):
  https://www.iso.org/standard/77461.html

## Community / open tooling

- QIF Community on GitHub (free tools, issues/wiki, instance data):
  https://qualityinformationframework.github.io
- DMSC open-source QIF applications and generators (C++, C#, Python) referenced from
  the QIF Community; see the implementation guide PDF (Action Engineering/DMSC)
  https://www.action-engineering.com/wp-content/uploads/DMSC-Bob-Stone-QIF-Symposium-2017.pdf

## Educational / industry material

- "The Complete Beginner's Guide to QIF Implementation" (public PDF, Action
  Engineering / DMSC):
  https://www.action-engineering.com/wp-content/uploads/DMSC-Bob-Stone-QIF-Symposium-2017.pdf
- Origin International QIF overview (industry explainer):
  https://info.originintl.com/solutions/qif

## Note on redistribution

The QIF standard and XSDs are free for implementers under DMSC's terms but their
license governs use/redistribution: point to the official download and record the
license in THIS README rather than re-hosting the bundle. The ISO 23952 sales text is
ISO-copyrighted.
