# MIL-STD-31000 — Official Reference Sources

Links verified against the live network at the time of writing. The standard is
public domain (Distribution A, U.S. Government work); ASSIST QuickSearch is the
source of record.

## Official / DoD sources

- ASSIST QuickSearch — DoD repository of record; search "MIL-STD-31000":
  https://quicksearch.dla.mil
- DoD Standardization (Defense Standardization Program) portal:
  https://www.dla.mil/HQ/InformationOperations/Offers/Services/Standards
- NIST MBE Summit 2024 — MIL-STD-31000 in Acquisition (public briefing, Jeff
  Windham, US Army):
  https://www.nist.gov/document/2024-mbe-summit-windham-mil-std-31000-technical-data-packages-acquisition

## Related standards referenced by the TDP standard

- ASME Y14.47 (3D model data / 3D PDF interchange) — ASME catalog, paywalled:
  https://www.asme.org/codes-standards/find-codes-standards (search "Y14.47")
- ASME Y14.41 (Digital Product Definition Data Practices), see
  standards/asme-y14.41 in this repo.

## Note on redistribution

MIL-STD-31000C is unclassified, Distribution A, approved for public release —
freely redistributable. We keep pointers to ASSIST as the canonical source rather
than mirroring the PDF, keeping the repo a catalog of pointers plus the acceptance
test.
