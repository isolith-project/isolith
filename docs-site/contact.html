Contact

Isolith is maintained by a small team. Email is the channel that works; there are no forms and no tracking on this site, so nothing is collected about you here. Which address to use depends on what you are writing about.

AddressWhat it is for
hello@isolith.dev General: questions, evaluation, partnership and teaming, press, anything that is not security or conduct.
security@isolith.dev Security findings, and only security findings. This is the private path; see the security page.
conduct@isolith.dev Code-of-conduct reports, per the Contributor Covenant; see CODE_OF_CONDUCT.md in the repository.

Response expectations

General mail is read by a human maintainer, not an autoresponder. Security mail has a written response commitment (see the security page); general mail is answered on a best-effort basis. If your question is a support question, read the getting-started guide and the admin guide first; the support statement in the repository says plainly what support exists and what does not.
