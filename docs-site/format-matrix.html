Format capability matrix

What each OEP reader opens, and at what fidelity. Every row below maps one-to-one to a committed general-availability (GA) gate report - the measured result of that reader on real material. Nothing here claims more than the cited report verified. Where a reader has a documented limit, the limit is a row of its own.

How this table is kept honest

The page renders format-matrix.json (same data, machine-checkable), and scripts/p13t03-format-matrix-check.py spot-checks that data against the committed GA matrices on every run:

  • P4 GA gate matrix (corpus/ga-gate-p4-matrix.json): the table must reproduce the committed totals (e.g. matrix cells=64, PASS 14 / FAIL 2 / SKIP 48; the 2 FAIL cells are circular runout + tolerance modifiers) and the within-epsilon accuracy row.
  • P2 and P3 GA gate reports: the numbered run summaries (no FAIL rows; open/skip classifications) are encoded as truth anchors only if the committed report text is present on the ref.
  • If a ground-truth artifact is absent on the ref, the checker classifies that leg SKIP with a reason - it never reports a fabricated PASS and never fails the build for a missing artifact.

The doctrine is the same as the GA gates themselves: exit 0 iff no FAIL cell anywhere, and a capability is only ever claimed at the exact fidelity a measured run verified.
