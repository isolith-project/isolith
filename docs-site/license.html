Legal clarity

License

Isolith is a per-crate hybrid-licenced open-source program. The boundary is a per-crate decision, not a prose statement, and it is enforced in CI. The legal texts are the unmodified canonical versions at the repository root; this page states where each one applies.

The boundary, in one line

Apache-2.0 for applications and libraries. AGPL-3.0 for the server, the PDM, and the P2P orchestration components.
Part of the stackLicenseWhy
Format readers (oep-cgr, oep-3dxml, oep-step, ...)Apache-2.0libraries
Geometry core and model (oep-geo, oep-engine-occ)Apache-2.0library
Applications (shell, drafting, viewer, ...)Apache-2.0applications
Self-hosted PDM server (oep-pdm) and its web UI (oep-web)AGPL-3.0server/PDM
P2P lane scheduler, workers, sandbox, state (oep-lane, oep-worker, oep-sandbox, ...)AGPL-3.0P2P orchestration
Docs server on the delivery stack (oep-docs)AGPL-3.0server, same compose as the PDM

Three rules that close the open questions

  • Per-crate. Every crate under crates/ is declared as a whole under exactly one license in its Cargo.toml, and CI enforces that declaration against a committed boundary map. Cross-crate links do not change a crate's license.
  • Consumption does not relicense. A library consumed by an AGPL component stays Apache-2.0; the consumer's license does not change the consumed crate's grant to third parties. When the combined server work runs as one program, the AGPL applies to that combined work the same way it always does to a Modified Work.
  • Shared contracts follow the server. A crate whose only job is the contract of the AGPL runtime (the P2P job spec and state, oep-job and oep-state) is AGPL-3.0.

The files at the repository root

  • LICENSE - the index stating which license applies where.
  • LICENSE-APACHE - Apache License, Version 2.0 (unmodified).
  • LICENSE-AGPL - GNU Affero General Public License, Version 3 (unmodified).
  • NOTICE - third-party attribution, generated from Cargo.lock and verified in CI.
  • docs/licensing-boundary.md and docs/licensing-boundary.json - the human-readable and machine-checkable boundary map.

No GPL-3.0 in delivered software. The license list deliberately excludes GPL-3.0, because defense-procurement legal review routinely disallows it; the boundary map and the CI license allow-list enforce that there is none among the delivered dependencies.

Contributions

Contributions are accepted under the Developer Certificate of Origin with no Contributor License Agreement and no copyright assignment: code is submitted under the license of the directory it lands in, per the DCO in CONTRIBUTING.md. Copyright stays with each contributor.
