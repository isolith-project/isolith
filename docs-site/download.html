Installers for Windows, macOS and Linux ship from GitHub Releases, with a SHA-256 checksum sidecar next to every file. This documentation site hosts no binaries and no source downloads: the artifacts live on GitHub, and you verify them by checksum before you run anything.

Current release: 2027.1.0-rc2

2027.1.0-rc2 is the interop and PDM foundation release: the format readers, the geometry core, the self-hosted PDM, and the delivery stack. It is a release candidate, not the product GA, and it does not claim to be the editor. The changelog and release notes are on the releases page.

Installers are published at the project's GitHub Releases page. The repository address is the single placeholder constant SITE-REPO-URL in docs-site/site.json: it is substituted at site generation, and the real GitHub address lands there when the GitHub migration completes.

Checksums, and why you check them

Every release publishes a SHA256SUMS file alongside the artifacts, listing the SHA-256 of each file. Verify before install: 

sha256sum -c SHA256SUMS

All output must say OK. A mismatch means the file is not the file the release signed: stop and re-download from GitHub directly. The release manifest itself is also signed (detached OpenPGP signature) so a tampered index is detectable on its own.

The checksums for the current release, 2027.1.0-rc2, as committed by the release gate (in dist/2027.1.0-rc2): 

1f2d4adcf5b535095f04c189fac30f59814add0b2c52ac6fe8c27a103612ac08  RELEASE-MANIFEST.json
35a33bc3a6bef18ad29fc2df676f70fd707be071b293467a071683ded855cd9a  SHA256SUMS
5895edab20317857a816c8788274355d285ea43adc6db225de6695a7ecf60dfb  CHANGELOG-2027.1.0-rc2.md

The full per-artifact list is inside SHA256SUMS itself; the hash of that file is listed above so the list can be checked for tampering before it is even read.

Windows: your SmartScreen will warn, and that is expected

Windows installers are unsigned today. The Windows build is not yet Authenticode-signed (code signing lands in a later release), so Windows SmartScreen will show a warning when you run the installer. That warning is expected. Do not bypass it by disabling SmartScreen globally; instead verify the checksum above, then allow this one file. If the checksum matches, the file is the release file.

Export control, in one short paragraph

Isolith is published open-source software and self-classifies as EAR99 general-engineering software, not ITAR technical data and not on the Commerce Control List. This is a self-classification, documented under workstreams/security/export-control/, not a formal government advisory opinion or any CCATS determination. Customer data that runs through an Isolith deployment is classified by the customer's own accredited deployment, not by this project. Isolith makes no claim of ITAR certification, and none is implied by this page or any other page on this site.

Source

The source is open. Check it out, build it, read it: 

git clone SITE-REPO-URL isolith

The license boundary (Apache-2.0 for applications and libraries, AGPL-3.0 for the server/PDM and P2P orchestration) is stated precisely on the license page.
