# Surface-representation corpus: Web3D Consortium LatticeXvl (XvlShell)

These X3D files are the public, license-clean instantiation of the exact
"surface mesh" representation family this program calls a Gregory-patch
surface rep: a coarse mesh with faces / edges / vertices plus per-vertex and
per-edge ROUNDING WEIGHTS, which a compliant viewer reinterprets into a smooth
surface made of Gregory patches. Lattice Technology published these as the open
demonstration of the XVL Lattice structure, and Dassault Systèmes licensed the
same lattice/Gregory technology for 3DXML's surface data (P3-M2 uses these as
the real-material surface reps to decode to NURBS).
