# 3DXML sample files in this directory

These 3DXML files were located as public samples (P1-M1-T02) and committed
because their hosting projects are permissively licensed, so the sample
files are redistributable in turn. Each file ships with attribution below.

Source A: trimesh model fixtures
- Repository: https://github.com/mikedh/trimesh (MIT License)
- Files: cube1.3dxml, blocks.3dxml, cycloidal.3DXML, FM1_satellite.3DXML, machinist.3DXML
- Author geometry authored in CATIA/Abaqus lineage, stored as 3DXML ZIP archives.
- License: MIT (project license applies to the repository and its sample models).
- Attribution: (c) trimesh contributors, reproduced from mikedh/trimesh models/.

Source B: i2e-haw-hamburg/cad-in-unity
- Repository: https://github.com/i2e-haw-hamburg/cad-in-unity (Apache-2.0)
- File: quad.3dxml
- ASCII XML 3DXML (schema 4.3), generated by CATIA V5 2009, included for Unity
  CAD loading examples; kept here because the file is standalone ASCII 3DXML
  and the host project is Apache-2.0.
- License: Apache-2.0.
- Attribution: (c) i2e-haw-hamburg contributors, reproduced from cad-in-unity.

Files NOT committed here (reference-only, see P1-M1/3dxml-samples.md):
- Dassault official 3D XML gallery sample (press_rink_axe_fta.3dxml): hosted on
  www.3ds.com for free download, but 3ds.com does not state a redistribution
  license for it, so it is catalogued (URL + sha256) but not checked into git.
- DMG-Lib "aircraft landing gear" 3DXML: academic library whose download terms
  are private, non-commercial, single-download only; not redistributable into a
  shared repo.

If any copyright holder objects to a committed file, remove it and update the
catalog and the acceptance test's COMMITTED_SAMPLES map.
